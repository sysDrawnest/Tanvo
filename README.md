#  TANVO 

This repository contains the proprietary, production-ready source code and architectural foundation for **TANVO**—a premium Indian handloom and heritage fashion e-commerce platform dedicated to showcasing authentic, artisan-crafted textiles from Odisha.

Built using **React 19, TypeScript, Tailwind CSS, Zustand, Node.js, Express, and MongoDB**, TANVO combines modern engineering with timeless craftsmanship to deliver a refined, high-performance digital shopping experience.

This repository includes the core frontend, backend services, design system, state architecture, inventory workflows, admin dashboard, WhatsApp Commerce System, and custom business logic powering the TANVO ecosystem.
