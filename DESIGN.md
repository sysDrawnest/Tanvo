# TANVO — Premium Heritage Design System

## Brand Definition

TANVO is a luxury Indian handloom heritage ecommerce platform focused on Odisha craftsmanship.

The brand represents:

- authentic handloom traditions
- artisan stories
- generational craftsmanship
- cultural heritage
- timeless Indian textiles

TANVO is not a marketplace.

It should feel like:

A heritage fashion house preserving centuries of craft.

The customer journey:

Discover → Trust → Connect → Own

# 11. Mobile First Strategy

Primary experience:

Mobile.

Priority:

Mobile > Tablet > Desktop

Mobile should include:

- large product photography
- easy thumb navigation
- simple checkout
- swipe galleries
- bottom sheets when useful

Do not create a desktop website compressed into mobile.
